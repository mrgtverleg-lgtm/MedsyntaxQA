🦀 **Medsyntax Framework: what's new** (still under construction!)

Medsyntax Framework helps you build a literature search step by step and checks the syntax while you type.

**Structure your question**
• Pick a mnemonic: PICO, PICOS, PICOT, PECO, SPIDER, SPICE, ECLIPSE or PIRD, or start without a framework and make your own concept blocks
• Save your own mnemonic, and share it with colleagues as JSON
• *Split concept*: several concepts under one letter, e.g. P = (ICU) AND (heart failure)

**11 databases**
PubMed, Embase, Ovid, CINAHL (EBSCO), MEDLINE (EBSCO), PsycINFO (Ovid and EBSCO), Cochrane Library, Web of Science, Scopus and Europe PMC. The examples are rewritten in the syntax of the database you choose.

**Syntax checks**
• Brackets: how many, which ones have no partner, and the first stray one highlighted
• Two operators in a row (AND OR), an operator with nothing before or after it, empty brackets
• Every field code checked for the chosen database ([tiabs], .ti,ab,k., 'term'/xx, T=)
• Proximity operators without a number (NEAR/), and proximity written as words: adj3, N3, NEXT, NEAR, SAME

**MeSH check** 🆕
PubMed MeSH terms become links to NCBI MeSH and are checked against the NLM MeSH API: found, entry term, replaced, deleted or not found, with "Did you mean" suggestions.

**Multisearch (line by line)** 🆕
Paste a search history from Embase, Ovid and others (also straight from a spreadsheet). It's split into concepts, limits and exclusions. Copy it as a table for Word or Excel, or download it. There's an example for every database.

**Sharing**
One link holds the whole search, framework included.
